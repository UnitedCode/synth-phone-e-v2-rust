# Daisy conformance

The [conformance ledger](https://github.com/UnitedCode/virtual-daisy/blob/main/docs/conformance.md)
is maintained with the standalone Virtual Daisy models. The
[pinned copy](../tools/virtual-daisy/docs/conformance.md) matches this project's submodule revision.

A functional simulation pass does not establish hardware timing or analog fidelity.
See the [integration guide](virtual-daisy.md) to run Synthphone firmware.
